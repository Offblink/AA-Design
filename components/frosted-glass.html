为什么值得借鉴

  1. 配方拆成五层，每层可独立调校。wisland 的 paintEvent() 用 1) 阴影 / 2) 玻璃底 / 3) 色调+光泽 / 4) 轮廓 编号注释把配方分层（island.py:953、970、991、959），改任意一层不动其它层，主题切换也只是换色值。
  2. 交叉淡入消灭背景跳变。新截图到来时先铺旧纹理、再按 fade 叠新纹理（island.py:970 注释「新截图与上一张交叉淡入，避免跳变」），0.25s 内完成，身后画面刷新不会「啪」地跳一下。
  3. 收起时预截取展开尺寸背景。源码注释原话：「收起时也预先截取展开尺寸的背景：打开的第一帧就有正确的玻璃，不会闪」（island.py:909）——把昂贵的准备藏在状态切换之前。
  4. 阴影用多层半透明描边廉价近似。「柔和阴影（几层半透明描边，廉价近似）」（island.py:953），三圈描边代替高斯模糊阴影，几乎零成本。
  5. 外暗内亮双描边勾出玻璃厚度。外侧 1.6px 极淡暗线 + 内侧 1px「上亮下暗」高光渐变（island.py:959-964），立体感全靠这两条边，而不是投影。

实现要点

  1. 截取管线四步：glass.py:18 DOWN = 12 缩小 1/12（越大越糊）→ glass.py:69 grab_tiny() HALFTONE 面积平均截屏（:84 特意不用 CAPTUREBLT，它会让分层窗口闪烁）→ glass.py:56 _blur() 3×3 平均，第 k 张按 1/k 不透明度叠加，结果正好是平均值不会变亮 → glass.py:208 brush_for() 把小图按 rect/tiny 比例 scale 回窗口坐标当画刷。
  2. 判变与平滑：glass.py:193 _capture() 连做两次 _blur(_blur(img))；再缩到 8×4 当指纹（:195）、缩到 1×1 取 pixelColor 算亮度（:196-197 Rec.709 权重），指纹变了 _on_backdrop(changed=True)（island.py:936）才重置淡入计时。
  3. 色调与光泽数值：dark 主题 tint (28,28,34,120)（theme.py:88）≈ CSS rgba(28,28,34,.47)；纵向光泽 island.py:995-997 顶部白 alpha 26 if not theme.dark else 14（深色 14、浅色 26）→ 50% 处 0 → 底部 10。
  4. 描边与阴影数值：rim 用 outline (0,0,0,70) 1.6px + 高光渐变 rim1 (255,255,255,60) → rim2 (…,14) 1.0px（theme.py:91、island.py:960-964）；阴影 path 下移 1.5px 后描 (14,5)(8,9)(4,14) 三圈，宽度递减、alpha 递增（island.py:954-955）。
  5. 交叉淡入：island.py:973 fade = (perf_counter − _bd_fade_t0) / 0.25，旧纹理铺底、新纹理按 fade 叠加；触发点在 _on_backdrop（island.py:940-942 只有 changed 才记 _bd_prev/_bd_fade_t0）。
  6. 浏览器近似：网页截不到「身后屏幕」，用 backdrop-filter: blur(18px) 近似整条截取管线；wisland 是交叉淡入玻璃里的两张纹理，这里改为两张背景 canvas 交叉淡化 0.25s 来演示同一手感。真实 wisland 还会降频：静止收起时 island.blur_fps 默认 10 再压到 3fps（island.py:902 _request_backdrop()）。
