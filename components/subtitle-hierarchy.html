为什么值得借鉴

  • 双通道信息层级：上行原文 12px × 透明度 0.62，下行译文 15px DemiBold × 全亮——字号与透明度同时分工，视线默认落在译文上，原文只是可选的上下文（源码注释「上面日语（小字，较淡），下面中文（大字）」）。
  • 掐头保尾的省略：字幕是流式到达的，最新信息永远在句尾；太长时用 ElideLeft 保留结尾（「最新的话」），丢掉的是已经说完的开头，读到的始终是刚说的那半句。
  • 固定 640×60 容器：句子长短差异巨大，宽度恒定意味着说话时胶囊不会一直伸缩抖动——「固定宽度：说话时不会一直伸缩」，容器安静，内容才好读。
  • 7 秒阅读缓冲：最后一句说完后保留 7s 再回原视图，够读完一行译文；安静超时自动回切，不打断音乐 / 时间视图，也不需要用户任何操作。
  • 字幕是临时仲裁，不是新页面：mode() 里临时活动 > 字幕 > 原视图，字幕结束自动落回常态，同一块胶囊复用全部场景，没有窗口切换成本。
  • 草稿与定稿共用一条覆盖路径：实时译文增量、最终译文都走 set_sub(zh=…) 原地覆盖，同时刷新读秒——「内容更新」而不是「新事件」，读秒自然续期，不会闪断。

实现要点

  • 三个常量定死：H_SUB = 60、SUB_HOLD_S = 7.0、W_TEXT = 640（compact.py:21-23）；字幕态尺寸 = W_TEXT + nb×12 × 60，每个未读圆点 +12px（compact.py:419）。
  • 行几何按胶囊中心对齐：上行矩形 y = cy−22 高 18、下行 y = cy−3 高 24（compact.py:493-494），均水平居中；原文 ui_font(12) 画笔 alpha 0.62（compact.py:483、496），译文 ui_font(15, DemiBold) alpha 1.0（compact.py:483、499）。
  • ElideLeft 流程：先 " ".join(text.split()) 归一空白 → 宽度 ≤ 可用宽就原样输出，否则 elidedText(…, ElideLeft)（compact.py:486-490）；本页用 canvas measureText 二分复刻同样的「… + 尾部后缀」。
  • 仲裁与读秒：sub_active = sub_on ∧ (jp∨zh) ∧ now−sub_t < 7.0（compact.py:357-358）；set_sub 只写文本并刷新 sub_t（compact.py:350-355），所以草稿、定稿、原文任何一次到达都自动续 7 秒。
  • 切换动画双层进行：内容 0.28s ease_out 淡入（compact.py:434），胶囊宽高用阻尼弹簧追目标 k=460、ratio=0.64（island.py:570-571；初始 k=300、ratio=0.62，island.py:239-240），弹簧方程移植自 anim.py:8-41。
  • 信号接线：partial / segment → set_sub(jp)、live_zh / final_zh → set_sub(zh)、running_changed → set_sub_running（app.py:328-351）；注意新句到达只覆盖 jp，zh 槽留着上一句直到新译文到达（app.py:333-341 不清 zh），定稿直接覆盖草稿。
