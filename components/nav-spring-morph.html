为什么值得借鉴

  • 整排落在玻璃上，不靠底色分区。wisland 顶栏「标签没有背景色和分割线，图标/文字直接落在玻璃上」（nav.py:2-5），选中的项才展开文字，信息密度按需分配，岛体不被一排按钮填满。
  • 高亮和展开是同一个动作。模块注释写明「切换时每项宽度都由弹簧驱动（欠阻尼 → 弹性缓动），底块跟着宽度一起流动」（nav.py:6）——pill 不是另起一段过渡，宽度怎么流它就怎么流，视觉上只有一个物理事件。
  • 文字永远不会溢出。「文字：随宽度展开渐显，裁剪在本项矩形内」（nav.py:217），展开中途文字被容器截断是设计的一部分，切换过程没有跳字、压字，也不会窜进邻项。
  • 两级反馈分得清「可点」与「已选」。hover 只给极淡圆底（主题色 × hover × 0.8）和图标不透明度 0.55→1（nav.py:208-213），选中才有 pill 和文字，不靠加粗、变色堆砌。
  • 滚轮也能翻页。（nav.py:191-193）手不用离开滚轮即可切换上一项/下一项，与点击一起覆盖两种高频输入，7 个页面来回翻不需要瞄准。
  • 收起宽度锁死 34px。（nav.py:21）未选中项恒为图标宽，整排只在有限区间内流动，灵动岛轮廓稳定不抖。

实现要点

  • 每项一个宽度弹簧 Spring(ICON_W, 260, 0.56, 0.05)（nav.py:40）：积分 c = 2·ratio·√k（anim.py:16），每帧拆 ceil(dt/(1/240)) 个 240Hz 子步解 a = −k(x−target) − c·v（anim.py:32-42）；ratio=0.56<1 欠阻尼，收和展都带 1~2 次回弹。
  • hover 是 Spring(0, 400, 1.0, 0.01)（nav.py:41）：ratio=1.0 临界阻尼，只平滑淡入淡出、不回弹，与宽度的弹性形成节奏对比；圆底 alpha = 主题色 × h × 0.8，图标 a = 0.55 + 0.4·h（nav.py:210、213）。
  • 展开目标 full_w = ICON_W + 文字宽 + 46（右侧留白，nav.py:38），收起目标 ICON_W = 34（nav.py:21）；绘制宽下限 max(ICON_W*0.7, x)（nav.py:118），回弹冲过头也不会把图标列压没。
  • 文字进度 prog = clamp((w − ICON_W)/extra, 0, 1)（nav.py:219），prog > 0.02 才画、裁剪区右缩 4px（nav.py:220-222），文字左缘钉在 ICON_W − 4 = 30px；pill 圆角 = 矩形高/2 全胶囊（nav.py:203），组内 gap=16、整组居中（nav.py:22、135-137）。
  • badge 红点 #ff453a 半径 3.2，圆心锚在 r.x + ICON_W/2 + 7, r.y + 8（nav.py:228-232），随项一起移动；wisland 用 nav.set_badge("msg", n) 挂未读数（app.py:291）。
  • _kick/_tick（nav.py:98-113）用 16ms 定时器驱动，所有弹簧 rest——|x−target| < eps 且 |v| < eps×8（anim.py:45-46）——就停表零 CPU；本页用 rAF 复刻同一策略：全 rest 后帧循环停止，读数区状态变为「帧循环已停」。
