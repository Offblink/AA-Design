为什么值得借鉴

  • 按压反馈不是整体缩放，而是「光标处凹进、其余略鼓」的软材质形变——手指按在水滴上的直觉一致（island.py:828 注释原话）。
  • 凹陷中心每帧以 0.3 的比例平滑追赶光标，拖得再快凹陷也不会瞬移，形变自带「惯性」（island.py:269 注释「平滑后的按压位置（凹陷跟着鼠标滑动）」）。
  • 松开用欠阻尼弹簧回弹，「弹回时会外鼓几下」（island.py:1064 注释）——比 ease-out 更像液体恢复表面张力，是「活的」手感。
  • 按压力度随光标位置连续变化：越靠中心越强（depth^1.4），边缘几乎不变形（island.py:1049 注释「越靠近中心挤压越强（边缘处几乎不变形）」），贴边区域留给液桥逻辑，交互热区不打架。
  • 形变只作用于「远离屏幕边」的外侧半边，贴边 30% 恒定不动（island.py:789 注释「外侧半边（含两端圆角）都参与」）——按的是外表面，锚点始终稳。
  • 体积守恒（+0.35 补偿）让凹陷伴随邻近鼓起，「软体感」才成立；本页开关可直接对比有无补偿的差异。

实现要点

  • 弹簧：Spring(0, 380, 0.55, 0.004)（island.py:267），c = 2·ratio·√k（anim.py:16），每帧按 1/240 s 子步进积分（anim.py:37），静止判据 |x−target| < 0.004 且 |v| < 0.032。
  • 按下驱动：depth = 1 − min(1, hypot(nx,ny))、target = depth^1.4（island.py:1057-1058），poke.to(target, 260, 0.75)（island.py:1061）；松开 poke.to(0, 380, 0.55) 欠阻尼回弹（源码同场景 island.py:1064 用 to(0, 300, 0.22)，注释「欠阻尼：弹回时会外鼓几下」，同为 ratio < 1）。
  • 高斯凹陷：u0 = 光标 x，clamp 到 [cx−half, cx+half]、sig = half·0.5（island.py:797-798），g = exp(−0.5·d²)（island.py:827），disp = amp·wgt²·(−g + 0.35·(1−g))，amp = clamp(pk, −0.6, 1.2)·8.0（island.py:791、828）。
  • 边缘权重 wgt = clamp((v − 0.3·depth)/(0.7·depth), 0, 1)（island.py:824）：贴边 30% 恒定不动、外侧渐变参与；「体积守恒」开关即去掉 +0.35·(1−g) 补偿项。
  • 轮廓按 4 px 步长采样（island.py:785 body_points(lbody, radii, 4.0)），Catmull-Rom 转三次贝塞尔闭合（shape.py:142 poly_path()）；贴边两侧内凹圆角 FILLET = 13（island.py:38）。
  • 内容随按压缩放 scale(1+0.05·pk, 1−0.16·pk) 并 clip 到形变路径内（island.py:1023、1025）；凹陷位置平滑 poke_sm += (pt − poke_sm)·0.3（island.py:594）。
