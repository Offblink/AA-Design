为什么值得借鉴

  • 一个悬停信号驱动整卡。封面 h、进度条 hover、卡片反馈全部来自同一个 Spring，放大、上浮、柔光、变粗同步呼吸；不会出现「各控件各自动一下」的割裂感。
  • 主色提取零成本。封面缩到 1×1 取那一个像素 = 全图平均色，Qt/浏览器的平滑缩放自动做面积平均，不遍历像素、不引库，换封面瞬间完成。
  • 平均色提亮后才配当「光」。原始均色通常偏灰，HSV 里饱和 ×1.4+40、明度保底 170——辉光是光源，要比当颜料的底色更亮更艳。
  • 微交互克制不抢内容。放大 7%、上浮 2.5px 都是很小的位移，配合柔光足以传达「可点」，符合灵动岛「内容为主、反馈为辅」的气质。
  • 进度条 hover 变粗即提示。4→7px 同时填充提亮，点击目标变大好点中（费茨定律），「变粗 = 可拖动」不用加任何说明文字。
  • 柔光按需绘制。h≤0.01 直接跳过辉光，静止时零额外绘制；离开悬停后 α 随 h 线性归零，淡出自然、无残留。

实现要点（wisland 真实参数）

  • 缩放 / 位移 / 柔光：s = 1.0 + 0.07*h，中心上移 2.5*h；径向渐变圆心 = 封面中心 +(0,6)、半径 = 封面宽×0.8、中心 α=round(150*h) 外缘 0，裁剪圆取 cr.adjusted(-10,-6,10,14)（CoverView 版是 ×0.75、(-8,-4,8,14)）。home.py:134-148
  • 取色管线：q.scaled(1,1,IgnoreAspectRatio,SmoothTransformation).pixelColor(0,0) → getHsv() → fromHsv(max(0,h), min(255,int(s*1.4)+40), max(170,v))。home.py:233-236
  • 封面裁圆角：rounded_pixmap(img, 58, 13, dpr=2.0) 输出 116×116 位图，裁剪半径 13×2=26 物理 px（视觉 13 逻辑 px），KeepAspectRatioByExpanding 居中裁切防拉伸。widgets.py:597-615
  • 悬停物理：enter to(1.0, 260, 0.6)、leave to(0.0, 220, 0.8)（回程更硬、不来回晃），16ms 步进内按 1/240s 子步做半隐式欧拉积分；|x−target|<0.004 且 |v|<0.032 判静止停表。anim.py:8-46 / home.py:200-216
  • 进度条：th = 4 + 3*hover（4→7px），填充 theme.text(0.85 + 0.15*hover) 由 0.85 提到 1.0，且与封面共用同一 h。home.py:55、62
  • 标题压封面：底边 = cr.bottom()-12，文字宽 +20、整卡宽 −16 封顶并省略号截断，四向 1px 阴影（dark: 黑 α120）保证压在封面上仍可读。home.py:151-165
