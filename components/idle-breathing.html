胶囊吸在演示区顶边：圆角呼吸 + 边缘流光常驻；点击胶囊本体可播放 / 暂停音乐律动波（远离屏幕边的半边才会起伏）

为什么值得借鉴

  • 收起态也持续跑微动画。wisland _needs_frames() 原注释：「收起态：常态动画（圆角呼吸 + 边缘流光）持续运行」——挂在屏幕边缘的组件靠这点"活气"证明自己没卡死、没失去响应，用户余光即可确认状态，不需要任何文字提示。
  • 呼吸幅度只有 ±7%（FILLET = 13.0 → 12.09~13.91px）：近看有生命感、远看几乎静止。环境型挂件的动效是"氛围"不是"通知"，绝不能抢注意力。
  • 流光是可发现性线索。中心 alpha=80、笔宽 1px 的白色微光以 sin(t·0.55)（周期约 11.4 秒）沿边缘缓慢游走，含蓄地暗示"这条边可以交互"，比常亮的按钮或角标克制得多。
  • 音乐律动只动"远离屏幕边"的半边。法向权重 wgt < 0.3 的点完全不动——贴边侧永远锚定，律动发生在朝向内容的一侧，锚点稳、方向语义清晰。
  • 30/60fps 分级。只有常态动画时按空闲 33ms/帧（≈30fps）跑；音乐律动 / 表情 / 提醒等 busy 状态才切到 16ms/帧（≈60fps）——常驻动画的成本被压到最低，笔记本续航友好。

实现要点

  • 圆角呼吸是一行相位公式：fillet = FILLET(13.0) × (1 + 0.07·sin(t·1.7))（island.py:755-757）；形变速度还会额外撑开液面 + min(12, (|v_sw|+|v_sh|)·0.012)（island.py:758）。本页把呼吸后的 fillet 画成高亮内凹圆角 + 虚线半径辅助线，实时读数可看到 12.09~13.91 的摆动。
  • 流光 = 沿轮廓描边的径向渐变：QRadialGradient(pt, max(60, bb.width×0.35))（本例 440×0.35 = 154px），中心白色 alpha=80（暗色主题 55）、外圈 alpha=0，1.0px 笔宽 strokePath（island.py:1009-1012）；光斑位置 x = left + width × (sin(t·0.55)×0.5+0.5)、y 取 bbox 远边（island.py:1004-1006）。
  • 律动波公式照抄：pk = clamp(peak_fn()×1.5, 0, 1)（island.py:804），逐点法向位移 pk·2.4·wgt²·sin(u·0.09 − t·7)，wgt = 法线·远边方向，wgt < 0.3 直接跳过（island.py:810-816）。本页按 island.py:785 的 body_points(…, 4.0) 以 4px 步长采样轮廓（shape.py:75），位移后用 poly_path 的 Catmull-Rom→三次贝塞尔平滑闭合（shape.py:142），u 取屏幕水平坐标 px（island.py:815）。
  • 贴边内凹圆角复刻 neck_path()（shape.py:161）的单段三次贝塞尔：起点在屏幕边上 (c − (half + fillet), 0)，控制点用四分之一圆弧系数 K = 0.5523（shape.py:23），收进本体侧壁——即表面张力的 meniscus；本页左右两角逐点复刻该曲线。
  • fps 分级实现：anchored + 弹簧静止 + 收起时 setInterval(16 if compact.busy() else 33)，注释原话「表情 / 音乐律动 / 提醒时 60fps，空闲（只有圆角呼吸）时 30fps」（island.py:649-651）；_tick() 把 dt 钳在 [1/240, 1/30]（island.py:556）。本页 rAF 按同样的 16/33ms 门限出帧，badge 实时显示当前分级与实测帧率。
  • 播放开关的 pk 过渡用照抄 anim.py 的阻尼弹簧：c = 2·ratio·√k，取 k=300、ratio=0.62（island.py:239-240 Spring(cw,300,0.62,0.2)、anim.py:21），积分按 240Hz 子步进 n = ceil(dt/(1/240))（anim.py:32 Spring.step()）——帧率在 30/60 之间切换也不改变手感（源码里 pk 来自连续音频峰值 peak_fn、天然平滑，弹簧只在本演示的开关/滑杆处做平滑过渡）。
