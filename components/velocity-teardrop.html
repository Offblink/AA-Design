为什么值得借鉴

  • 形变本身就是速度反馈：拖拽时"往哪甩、甩多快"直接写在轮廓上——后缘拖多长、前缘鼓多少，用户不看任何数字就能感知运动状态，比光标样式或 toast 提示更前置、零认知成本。
  • 只在 speed > 30 px/s 才启用形变采样（island.py:784）：低速微调保持刚性几何，手抖不会被放大成"果冻感"；高速才有花活，安静时绝不打扰。
  • 非对称形变制造液体惯性错觉：后缘收窄 38%、整段拖尾 lag，前缘却只鼓 0.12·lag——前轻后重，像一颗有质量的水滴被甩出去，而不是刚体在平移。
  • 回正来自物理而非补间：速度取自阻尼弹簧的 v，松手后速度自然衰减且带一点余摆（ratio 0.78 < 1 欠阻尼），形状"活"过来的代价只有一次积分，不需要额外关键帧。
  • 形变是纯叠加层：deform 只改顶点、不改语义，同一份轮廓管线还能继续叠按压凹陷、播放波动 wave——一套顶点流服务多种效果，扩展不重写。

实现要点

  • 速度不是鼠标速度，而是位置弹簧的速度：vx, vy = fx.v, fy.v（island.py:710），fx/fy = Spring(0, 900, 0.78, 0.2)（island.py:241-242）——弹簧既平滑输入，又天然产生甩尾的速度峰值与松手余摆。
  • amt = clamp(hypot(vx,vy) / 2600, 0, 1)（shape.py:112）：2600 px/s 满形变封顶；lag = halfExtent · 0.6 · amt（shape.py:119），halfExtent = min(w,h)/2 + 12（island.py:818）。
  • 逐点 s = n·d 判前后缘（shape.py:126，1=前缘 −1=后缘），tf = (1−s)/2 归一；squeeze = 1 − 0.38·amt·tf^1.2（shape.py:130）只收窄后缘；push = −lag·tf^1.6 + lag·0.12·(1−tf)^2（shape.py:131）后缘拖尾、前缘微鼓。
  • 轮廓先 body_points 按 step=4.0 均匀采样成多边形（shape.py:75，island.py:785），形变后 poly_path 用 Catmull-Rom 转贝塞尔闭合（shape.py:142），泪滴边缘依旧光滑、无多边形棱角。
  • 弹簧积分 c = 2·ratio·√k（anim.py:16），每帧拆成 ≤ 1/240 s 的子步（anim.py:37），帧率波动不改变回正轨迹；帧间隔本身夹在 [1/240, 1/30]（island.py:556）。
  • HUD 与渲染同源：收窄 38·amt%、拖尾 lag px、鼓起 0.12·lag px 都由同一份 amt 直接代入公式，所见即所算。
