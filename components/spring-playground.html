为什么值得借鉴

  • 所有形变 / 位移共用同一个 Spring，整颗水滴的手感、节奏完全统一，不会出现「这个动画 Q 弹、那个动画匀速」的割裂（anim.py:2 模块注释）。
  • 欠阻尼（ratio < 1）自带过冲回弹，比手写 ease 曲线更有生命力；wisland 的导航切换、尺寸形变都靠它营造「弹性缓动」（nav.py:5 注释「欠阻尼 -> 弹性缓动」）。
  • rest 判定让定时器自己停帧：静止时 timer.stop()，零 CPU；一有交互再 _kick() 拉起，动画引擎不空转（anim.py:45、island.py:647）。
  • 阻尼系数 c 由 k、ratio 两个直觉量推导，调参时不用单独拧「阻尼」这种难理解的物理量（anim.py:16）。
  • 拖拽 / 抛出时把当前速度注入弹簧（gap.v = -v_toward），落点动量连续，不会「甩过去又凭空起步」（island.py:519）。
  • eps 按对象量级分级：导航 0.05px、岛屿几何 0.2px、按压形变 0.004——阈值越小越晚停帧，精度与开销各取所需。

实现要点

  • Spring 定义于 anim.py:8，默认 stiffness=300、ratio=0.8、eps=0.05；阻尼 c = 2·ratio·√k（anim.py:11/16）。
  • 积分是半隐式欧拉：先 v += a·h 再 x += v·h；按 ceil(dt / (1/240)) 做 240Hz 子步进，高刚度也不炸（anim.py:32 step）。本页 60fps 每帧 4 个子步、30fps 8 个。
  • rest 条件：|x−target| < eps 且 |v| < eps×8（anim.py:45-46）；step 开头先判 rest，已静止则直接吸附目标、不积分。
  • 本页预设均为源码真实值：导航宽度 k=260 / ratio=0.56 / eps=0.05（nav.py:40）、尺寸展开 k=420 / 0.62 / 0.2（island.py:383）、位置跟随 k=900 / 0.78 / 0.2（island.py:241）、贴边回吸 k=300 / 0.38 / 0.2（island.py:520）、按压 poke k=380 / 0.55 / 0.004（island.py:267）。
  • 每帧 dt 夹在 [1/240, 1/30]（island.py:556），切后台回来不会大跳；ratio 越接近 1 回弹越少，>1 过阻尼完全不越界。
