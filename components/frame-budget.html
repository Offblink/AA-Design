⏱️ 帧调度 — rest 停帧 · 30/60 分级 · 脏矩形 · 16px 网格

源出 wisland/ui/island.py:614 _needs_frames() · island.py:625 _tick()（16/33ms 分级）· island.py:806（脏矩形）· island.py:918（16px 网格）
演示区：胶囊在动时重绘（橙色框 = 本次脏矩形）；弹簧全部 rest 时 rAF 完全停止（绿灯）。空闲呼吸走 30fps，有活动走 60fps。

为什么值得借鉴

  • 静止 = 零开销：所有弹簧 rest 后直接停 rAF。常驻悬浮控件 99% 时间是静止的，每帧空转画一个「不动的动画」是纯浪费。
  • 30/60 分级：常态圆角呼吸 30fps（33ms）足够顺滑，表情/音乐律动才上 60fps（16ms）—— 按内容的运动速度分配帧预算，不按「有没有动画」一刀切。
  • 脏矩形：只重绘 old∪new 轮廓 +16px 边距。胶囊在 900×680 窗口里只占一小块，全窗重绘是 10 倍以上的浪费。
  • 16px 采样网格：毛玻璃截图区域对齐到 16px 网格 —— 轮廓每帧微动时采样区不跟着抖，省掉大量无意义的重截。
  • 这些策略叠起来的结论：性能是手感的一部分 —— 掉帧的弹性动画比没有动画更糟，所以宁可停帧也不降级画。

实现要点

  • _needs_frames()（island.py:614）：拖动 / 有水滴 / 背景在淡入 / 任一弹簧不 rest / 收起态常态动画 —— 全 false 就 timer.stop()。
  • 帧率分级在 _tick() 尾部：setInterval(16 if compact.busy() else 33)（island.py:657）—— busy = media/activity/pet/subtitle 模式或切换后 1.4s 内。
  • 脏矩形：dirty = old_path ∪ new_path + adjusted(±16)（island.py:806），只对这块 update()。
  • 毛玻璃采样按状态降频：移动 40fps、展开 10fps、收起 3fps、参与截图时静止 1~1.5Hz（island.py:922 _request_backdrop()）。
  • 截图线程自身还有 1/45s 节流（glass.py:165）—— 被连续唤醒也不会占满 CPU。
  • rest 判据是双条件：位置够近 且 速度够小（|v| < eps×8），防止在目标附近高速穿越时误停。
