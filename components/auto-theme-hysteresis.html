为什么值得借鉴

  • 中间亮度来回跳，双阈值治。源码注释原话「自动切换（带滞回，避免在中间亮度来回跳）」：暗→亮要 > 0.64、亮→暗要 < 0.42，中间留出 0.22 的死区，背景亮度在附近徘徊时主题岿然不动。
  • 越过阈值还得持续 3 秒。注释原话「身后画面要持续越过阈值 3 秒才切换，滚动的网页之类不会让玻璃来回闪」——一闪而过的白页、高光只算"路过"，计时立刻作废。
  • 先 EMA 平滑再判定。每次只信新样本 20%（0.8 / 0.2），截图噪点、光标闪白进不了决策，曲线也平滑到肉眼可调试。
  • 亮度标量零成本。身后画面缩到 1×1 取平均色、按 BT.709 加权，一个 0~1 的数就回答"身后是明是暗"，不做逐像素统计。
  • 自动只在 dark / light 两套里切。不自动跳进 rouge / sky 撞色，保证任何背景下股票、天气小字的对比度达标；另两套留给手动选择。
  • 平时喂亮度几乎零开销。没越阈时 feed 就是几次比较；_apply 发现 pal 没变不发 changed 信号，不触发重绘。

实现要点

  • EMA：lum = lum * 0.8 + in * 0.2（theme.py:141），初值 0.5（theme.py:134）。喂入节奏 = 身后截图节奏：展开态 1/blur_fps = 125ms（config.py:28 默认 8fps，island.py:927-928 取间隔，收起态限 3fps）——本页同为 8Hz。
  • 双阈值：_lum > 0.64 暗→亮（theme.py:144）、_lum < 0.42 亮→暗（theme.py:146），死区内沿用当前主题（theme.py:149 want = self.dark）。
  • 驻留：首次越阈记 _flip_since = now（theme.py:156-157），now - _flip_since < 3.0 直接 return（theme.py:159）；其间只要回到阈值内立即 _flip_since = None 清零（theme.py:151）。页内「注入越阈脉冲」= 1s 背离 + 1s 反向回撤，演示的就是这次清零。
  • 翻转：满 3 秒 _apply("dark" if want else "light")（theme.py:162），自动模式只 dark / light 二选一；_apply 仅 pal 变了才 emit changed（theme.py:169-175），静默帧零开销。
  • 输入链：island.py:937 theme.feed_luminance(self.backdrop.luminance)；luminance 来自玻璃截图缩 1×1 的 pixelColor × (0.2126, 0.7152, 0.0722)（glass.py:196-197）。
  • 「关闭滞回」把 0.64 / 0.42 合成单阈值 0.5、驻留 3 秒保留：游走 ±0.05 绕 0.5、周期 8s，每 4s 越线一次、计时刚好走满 → 主题每 4 秒翻一次；滞回开着则永不出死区，一对比就懂。
