为什么值得借鉴

  • 展开与收起是两段不等长的去抖：碰到后停 220ms 才展开、移开后等 450ms 才收起（island.py:1084 hover_expand_ms、:1096 collapse_delay_ms）。路过不误开，短暂移出也不闪收。
  • 收起只看 locks 集合是否为空（island.py:1091 if self.locks or self.pinned()）：菜单、查词、输入框任一在位就清零离场计时，用户正在操作的浮层不会被「鼠标移开」打断。
  • 单击是明确意图：展开的同时加 pin 锁并 600ms 后自动释放（island.py:1135-1136），给点击后的阅读留出确定窗口，再交还给悬停逻辑——点完不会立刻被收走。
  • 双击在收起态与展开态都能切「长关」（island.py:1147 toggle_long_off、:168 _BlankDoubleClick 展开后双击空白区）；长关时立即收起、不等鼠标移出、不弹任何提示（:1151-1155 注释）。
  • 形状先长到完整尺寸、内容才显示（island.py:576-577 注释与判据），收起时内容立即隐藏、玻璃形状再收回胶囊（:399 注释）——形变全程不出现「有内容、没有玻璃底」的穿帮帧（:456-457 注释）。
  • 悬停展开前检查鼠标左键没按住（island.py:1084-1085 GetAsyncKeyState(0x01)）：按住拖窗口扫过灵动岛时不会误弹。

实现要点

  • 阈值原样搬：悬停 220ms、离场 450ms、单击 pin 600ms、单击判定窗口用 Qt 的 doubleClickInterval（默认 400ms，island.py:1129）；wisland 的 _poll_hover 跑在 25ms 定时器上（island.py:304），本页同样每 25ms 轮询一次，渲染走 rAF。
  • 弹簧逐参数移植（anim.py:8-46）：阻尼系数 c = 2·ratio·√k（anim.py:16），rest 判定 |x−target|<eps 且 |v|<8·eps（anim.py:45-46），半隐式欧拉子步 ≤1/240s；形状展开 to(w, 420, 0.62)（island.py:383-384）、收回 to(cw, 460, 0.64)（:570-571）、初始 Spring(cw, 300, 0.62, 0.2)（:239-240），dt 钳制 1/240~1/30（:556）。
  • 内容显示判据逐帧检查 sh.x≥h−1 && sw.x≥w−1 && content_a.target<1（island.py:577），满足才 content_a.to(1, 700, 1.0) + content.show()（:579/:582）；expand() 先把内容几何设成最终尺寸并隐藏（:385-387「先隐藏，形状长大后再显示」），页面数据刷新再延迟 40ms（:440-442 _defer_show）让形变先跑。
  • 收起顺序固定：content_a.snap(0) → content.hide() → release_focus() → locks.discard("pin")（island.py:398-404），形状随后由 :570-571 的弹簧收回；收放态小脸用 compact_a 淡出 to(0, 900, 1.0)、淡入 to(1, 420, 1.0)（:380/:573）。
  • locks 四个来源：pin ← _single_click 600ms（:1135-1136）、focus ← request_focus（:1256）且前台窗口切走立即释放（:1039-1041）、menu ← 右键菜单弹出 / aboutToHide 释放（pages/system.py:201-202）、lookup ← 查词浮层 show / hide（lookup.py:101/106）。
  • 双击两条路径：收起态由 mouseDoubleClickEvent 先停掉单击定时器再 toggle_long_off（island.py:1142-1145），展开态空白区由 _BlankDoubleClick 事件过滤器拦截（:168-184）——保证第二次点击不会先触发单击展开。
