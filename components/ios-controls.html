为什么值得借鉴

  • 图标对比度翻转：白色填充越过左侧图标时图标立刻变深色、越过右端数值时数值也变深——任何填充比例下前景都保持可读，不需要为"半填充"状态单独设计中间色。
  • 整条轨道可点击可拖：iOS 控制中心的肌肉记忆是"点哪儿跳哪儿"，不必先抓住一个小把手，粗滑块（34px 高）让触控目标足够大。
  • 滑块不响应滚轮：wheelEvent 直接 e.ignore() 交给外层——指针停在滑块上时页面仍能正常滚动，避免"光标落进控件就滚不动页"的经典陷阱。
  • 磁贴颜色用弹簧插值而非硬切：关闭→打开时圆底从灰弹簧过渡到蓝，图标在 t>0.5 时翻白，过渡中途任何一帧对比度都够。
  • 分段底块"弹"过去而不是淡入淡出：位移本身即状态指示，眼睛跟着底块走，选中项的归属一目了然。
  • 统一的按压缩放（1 − 0.06×press）：所有控件共享同一对 hover/press 弹簧，按下有"被按进去"的触感，松手回弹，交互语言一致。

实现要点

  • 弹簧类移植自 anim.py Spring：阻尼 c = 2·ratio·√k，积分 a = −k(x−target) − c·v，按 1/240s 子步进；静止判定 |x−target|< eps 且 |v| < eps·8。
  • 滑块数值弹簧 shown = Spring(0, k=520, ratio=1.0, eps=0.002)；填充宽 max(height, width·v)（v>0 时至少留出一个圆高）；图标翻转阈值 v·width > height·0.8，数值翻转阈值 v > 0.9；按下点 x < height·0.9 视为图标点击而非拖动。
  • 磁贴：高 52、圆角 16、图标圆直径 d = height − 16 = 36；on_spring = Spring(0, k=380, ratio=0.85, eps=0.005)；圆底颜色在 track(255,255,255,34) → on #3b82f6 之间按 t 线性插值（含 alpha），图标 t > 0.5 翻白；副标题两级文字 12.5px/11px，off 时整体 0.45 透明度。
  • 分段：高 28，底块 x = cw·pos + 2、宽 cw − 4、圆角取自身高一半；pos = Spring(0, k=520, ratio=0.72, eps=0.002)，源码用 16ms 定时器固定 step(0.016)，ratio 0.72 让底块越过目标后回弹一次再停。
  • hover/press 弹簧来自 Hoverable：hover = Spring(0, 420, 1.0, 0.01)、press = Spring(0, 600, 0.7, 0.01)，press_scale = 1 − 0.06·press.x；磁贴在 wisland 中直接继承 Hoverable，本演示把同一对弹簧接到滑块与分段上，三个控件反馈一致。
  • 全部动画走自写 requestAnimationFrame 循环：任何弹簧 to() 唤醒循环，全部 rest 后停帧；无任何动画库。
