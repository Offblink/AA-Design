🧲 吸附状态机 — 加权选边 · 冲压挤压 · 回弹归位

源出 wisland/ui/island.py:490 _end_drag()（weights/速度投影）· island.py:615（snap→anchored）· island.py:689-697（冲过边缘挤压）
anchored → drag → snap → anchored
选边权重：top/bottom ×1.0 · left/right ×1.35（横向更难吸）

为什么值得借鉴

  • 松手不是「回原位」而是吸附到语义上最近的边：给四条边各算 gap、乘权重取最小 —— 交互结果可预期（「丢哪儿贴哪儿」），又用权重表达偏好（横放的胶囊贴左右边少见，×1.35 让它更难选中）。
  • 速度被继承：gap 弹簧的初速 = 松手瞬间朝边速度的投影（gap.v = -v_toward）—— 甩得越猛冲得越快，动能不丢，这是「物理感」和「玩具感」的分界线。
  • 冲过边缘不硬停：gap 变负时转成挤压形变（高度压到 62%、宽度 +1.1 倍），把穿透量视觉化成「撞扁了」—— 越界从 bug 变成打击感。
  • 回吸用欠阻尼 ratio=0.38（大幅回弹），沿边定位用 ratio=0.74（温和）—— 两个轴两种性格：垂直方向表演、水平方向稳定。
  • 状态机只有三个状态（anchored → drag → snap → anchored），且 snap 结束的判定是双弹簧同时 rest（island.py:615）—— 状态转移条件全部来自物理量，没有定时器。

实现要点

  • 选边：weights = {top:1.0, bottom:1.0, left:1.35, right:1.35}，edge = min(gaps, key=g×weight)（island.py:505-506）。
  • 松手三连：along.snap(初值) → along.v=v_along → along.to(clamp, 240, 0.74)；gap.snap(max(-4, 间隙)) → gap.v=-v_toward → gap.to(0, 300, 0.38)（island.py:514-520）。
  • 挤压：if g<0: squash=-g → h=max(h×0.62, h-squash)、w+=squash×1.1（island.py:689-697）—— 挤压量就是穿透深度。
  • 归位判定：mode=="snap" && along.rest && gap.rest → anchored，随后把 pos_frac 存进 config（island.py:615-626）—— 位置跨重启持久化。
  • 换边时旧液桥先 _break_neck() 留水滴（island.py:522-523）；新边 gap < JOIN=30 才重新伸出液桥。
  • along 范围夹取 lo..hi 留出 FILLET+EDGE_MARGIN 边距，胶囊不会顶到屏幕角（island.py:485 _along_range）。
